# ASK LOVELY RITA — MASTER ENGINE

This is the active development architecture for Ask Lovely Rita.

The original Snack prototype is preserved separately as a backup.

## Core systems

- Rita character and voice
- Age-based learning
- Randomized question engine
- Music worlds
- Interactive games
- BeatCoins and rewards
- Progressive difficulty
- Non-repeating question selection
- Expandable content database
- Modular character/theme/IP system

## Age groups

- Kids
- Adults
- Experts

## Design principle

The engine must allow music, questions, games, characters,
visual assets and future intellectual-property themes to be
changed or expanded without rebuilding the entire application.

## Development rule

Never modify the original backup project directly.
