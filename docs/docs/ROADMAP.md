# ASK LOVELY RITA — MASTER ROADMAP

## Project
Educational development and entertainment through music,
general knowledge, games and interactive learning.

## Core Vision
Ask Lovely Rita is a scalable educational entertainment engine
designed to grow through music, knowledge, games, questions,
audio, visual assets and age-appropriate learning.

## Development Principle
The engine must be modular so that themes, characters,
music worlds, questions, games and licensed intellectual property
can be changed or expanded without rebuilding the entire application.

## Difficulty Architecture

### Kids
Simple questions and games appropriate to age.

### Adults
More sophisticated knowledge and reasoning.

### Experts
Advanced questions requiring deeper knowledge,
reasoning and/or specialized understanding.

## Randomization
Questions and answer choices must be randomized so that
replaying the same game does not produce the same sequence.

## Music Architecture
The music library is designed to be expandable and adaptable.

## IP Strategy
The development engine should remain generic enough to support
original intellectual property and properly licensed third-party
music/characters where appropriate.

## Current Development Environment
